KAVI VISUALS WEBSITE
=====================

Brand: KAVI VISUALS
Photographer: Kavithennarasu
Style: Dark & Cinematic

FILES
-----
index.html  -> public website
admin.html  -> local admin prototype

FEATURES
--------
- Cinematic homepage
- Portfolio categories: Wedding, Portrait, Street, Nature
- About and Services sections
- Client enquiry form
- Enquiries saved locally and visible in Admin
- Admin photo upload/delete/category UI
- Responsive mobile layout

IMPORTANT
---------
This version is a fully working FRONT-END prototype. Browser localStorage is used for photos and enquiries, so it is suitable for testing/demo.

For a real public website, the next production step is to connect:
1. Cloud image storage
2. Database for enquiries
3. Admin authentication
4. Email notification when a client submits an enquiry
5. Optional WhatsApp notification
6. Custom domain/hosting

To preview:
Open index.html.
Then click Admin in the top menu.

The placeholder images are loaded from Unsplash, so internet access is needed to display them.
